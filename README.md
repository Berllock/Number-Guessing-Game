# 🎯 Number Guessing Game

Um jogo interativo de adivinhação de números via linha de comando (CLI). O programa desafia o jogador a descobrir um número secreto entre 1 e 100, com níveis de dificuldade e feedback em tempo real.

---

## 📦 Funcionalidades

- ✅ **Níveis de dificuldade**
  - Fácil (10 tentativas)
  - Médio (5 tentativas)
  - Difícil (3 tentativas)

- ✅ **Geração aleatória**
  - Número secreto entre 1 e 100

- ✅ **Feedback inteligente**
  - Indica se o número é maior ou menor que o palpite

- ✅ **Contagem de tentativas**
  - Mostra em quantas tentativas você acertou

- ✅ **Interface moderna**
  - Uso de *Text Blocks* e *Switch Expressions*

---

## 🛠️ Tecnologias Utilizadas

- Java 17+
- `java.util.Scanner`
- `java.util.Random`

---

## ⚙️ Como Usar

### Pré-requisitos

- JDK 17 ou superior
- Git instalado

### Instalação

```bash
git clone https://github.com/Berllock/Number-Guessing-Game.git
cd Number-Guessing-Game
javac Main.java
````

### Execução

```bash
java Main
```

---

## 🎮 Como Jogar

1. Escolha a dificuldade (1, 2 ou 3)
2. Insira seus palpites
3. Receba dicas (maior ou menor)
4. Acerte antes de acabar as tentativas

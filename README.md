# 🎯 Number Guessing Game

Um jogo interativo de adivinhação de números via linha de comando (CLI). O programa desafia o jogador a descobrir um número secreto sorteado aleatoriamente entre 1 e 100, oferecendo diferentes níveis de dificuldade e feedback em tempo real.

---

## 📦 Funcionalidades

✅ **Níveis de Dificuldade**  
Escolha entre:
- Fácil (10 tentativas)  
- Médio (5 tentativas)  
- Difícil (3 tentativas)  

✅ **Geração Aleatória**  
O número secreto é gerado dinamicamente entre 1 e 100  

✅ **Feedback Inteligente**  
O jogo informa se o número secreto é maior ou menor que o palpite  

✅ **Contagem de Tentativas**  
Mostra em quantas tentativas você acertou  

✅ **Interface Moderna**  
Uso de recursos recentes do Java como *Text Blocks* e *Switch Expressions*  

---

## 🛠️ Tecnologias Utilizadas

- **Java 17+**
- `java.util.Scanner`
- `java.util.Random`

# Number Guessing Game

Um jogo interativo de adivinhação de números via linha de comando (CLI). O programa desafia o jogador a descobrir um número secreto sorteado aleatoriamente entre 1 e 100, oferecendo diferentes níveis de dificuldade e feedback em tempo real.

## 📦 Funcionalidades

✅ **Níveis de Dificuldade**: Escolha entre Fácil (10 tentativas), Médio (5 tentativas) ou Difícil (3 tentativas).
✅ **Geração Aleatória**: O número secreto é gerado de forma dinâmica entre 1 e 100.
✅ **Feedback Inteligente**: O jogo informa se o número secreto é maior ou menor que o palpite atual.
✅ **Contagem de Tentativas**: Exibe em quantas tentativas o jogador conseguiu acertar.
✅ **Interface Moderna**: Utiliza recursos recentes do Java como *Text Blocks* e *Switch Expressions*.

## 🛠️ Tecnologias Utilizadas

*   **Linguagem**: Java 17 ou superior
*   **API Padrão**: `java.util.Scanner` para entrada de dados e `java.util.Random` para lógica do jogo.
